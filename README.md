# mend — a patch tool for every AI edit format

Applies AI-suggested edits to a tree of text files in four formats: unified diffs (with wrong line numbers), SEARCH/REPLACE blocks, V4A, and JSON edits. Built for the [make.fun bounty "Build mend"](https://make.fun/bounty/hidden-spec-cli-01-run-20261122).
